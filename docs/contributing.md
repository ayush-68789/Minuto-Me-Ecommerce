# Contribution workflow

**Owners:** Shared by all members; M1 maintains repository workflow guidance.

Use `feature/m<N>-<short-name>` branches from `develop` and open pull requests back to `develop`. Keep commits scoped to the owned feature. Coordinate changes to shared contracts before merging. Do not commit local environment files, generated dependencies, or secrets.

The initial repository has no feature implementation beyond the API health probes. Do not infer completion from a planned folder or ownership entry.
